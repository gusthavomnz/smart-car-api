║                        SMARTCAR  —  API REFERENCE                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

  Base URL       http://localhost:8080
  Protocolo      HTTP/1.1
  Formato        JSON  (Content-Type: application/json em toda requisição com body)
  Autenticação   JWT Bearer Token  —  Authorization: Bearer <token>
  Expiração      86 400 s (24 h)
  Timestamps     ISO 8601 sem fuso  →  "2026-05-19T14:30:00"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  AUTENTICAÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Rotas públicas (sem token)     POST /auth/cadastrar  |  POST /auth/login
  Rotas protegidas (token req.)  tudo em /sc/**  e  /fipe/**

  O token é obtido via POST /auth/login e deve ser enviado em todas as rotas
  protegidas no header:

      Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...

  O usuário autenticado é identificado exclusivamente pelo token.
  Nunca enviar usuarioId no corpo das requisições.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  CÓDIGOS DE ERRO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  400  Um ou mais campos do body estão ausentes, em formato inválido ou com
       valor fora dos aceitos pelo enum (ex: conservacao = "PERFEITO").

  401  Token ausente, malformado ou expirado. Também retornado no login
       quando e-mail ou senha são incorretos.

  403  Token válido, mas o recurso pertence a outro usuário.

  404  O recurso identificado pelo ID informado não existe.

  409  Conflito de unicidade — e-mail já cadastrado.

  Os erros 400 e 401 por filtro JWT não carregam corpo.
  Os erros 403 e 409 carregam a mensagem de erro do servidor.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ENUMS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Todos os valores de enum são case-sensitive e devem ser enviados em
  MAIÚSCULAS exatamente como listados.

  conservacao          Estado de conservação do veículo avaliado.
  ┌────────────┬──────────────────────────────────────────────────────────┐
  │  "NOVO"    │  Veículo zero km ou sem sinais de uso                    │
  │  "BOM"     │  Bom estado geral, revisões em dia                       │
  │  "REGULAR" │  Desgastes visíveis, pequenos reparos necessários        │
  │  "RUIM"    │  Problemas mecânicos ou estéticos significativos         │
  └────────────┴──────────────────────────────────────────────────────────┘

  statusResultado      Resultado da análise de precificação. Somente retornado.
  ┌──────────────────┬──────────────────────────────────────────────────────┐
  │  "OTIMO_NEGOCIO" │  preçoAnunciado ≤ 90 % do preço justo               │
  │  "NA_MEDIA"      │  preçoAnunciado entre 90 % e 105 % do preço justo   │
  │  "ACIMA_DA_MEDIA"│  preçoAnunciado entre 105 % e 120 % do preço justo  │
  │  "PESSIMO_NEGOCIO│  preçoAnunciado > 120 % do preço justo              │
  └──────────────────┴──────────────────────────────────────────────────────┘
  O "preço justo" é calculado pelo backend a partir do preço FIPE corrigido
  pela quilometragem e pelo estado de conservação do veículo.

  historicoAtivo       Indica se a avaliação está ativa. Somente retornado.
  ┌───────┬─────────────────────────────────────────────────────────────────┐
  │ "SIM" │  Avaliação visível no histórico do usuário                      │
  │ "NAO" │  Avaliação ocultada via soft delete (irreversível)              │
  └───────┴─────────────────────────────────────────────────────────────────┘


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ROTAS DE AUTENTICAÇÃO  (/auth)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─────────────────────────────────────────────────────────────────────────────┐
│  POST /auth/cadastrar                                           201 Created  │
└─────────────────────────────────────────────────────────────────────────────┘

  Cria um novo usuário. Não requer autenticação.

  Request
  ───────
  Campo   Tipo    Obrig.  Regra
  nome    String  sim     não vazio
  email   String  sim     formato e-mail válido, único no sistema
  senha   String  sim     não vazia

  Response  201
  ────────────────────────────────────────────
  Campo      Tipo           Exemplo
  id         Long           1
  nome       String         "João Silva"
  email      String         "joao@email.com"
  criado_a   LocalDateTime  "2026-05-19T10:30:00"

  Erros
  ─────
  400  campo ausente ou e-mail em formato inválido
  409  e-mail já cadastrado


┌─────────────────────────────────────────────────────────────────────────────┐
│  POST /auth/login                                                  200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Autentica o usuário e retorna o token JWT. Não requer autenticação.

  Request
  ───────
  Campo   Tipo    Obrig.  Regra
  email   String  sim     formato e-mail válido
  senha   String  sim     não vazia

  Response  200
  ─────────────────────────────────────────────────────────────────────────────
  Campo   Tipo    Descrição
  token   String  JWT a ser enviado em todas as requisições protegidas

  Erros
  ─────
  400  campo ausente ou e-mail em formato inválido
  401  e-mail ou senha incorretos


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ROTAS DE AVALIAÇÃO  (/sc)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Todas as rotas /sc exigem token. O usuário é identificado pelo token —
  nunca incluir usuarioId no body.

  Objeto AvaliacaoResponse  (retornado por todas as rotas /sc)
  ─────────────────────────────────────────────────────────────────────────────
  Campo            Tipo           Nulável  Descrição
  id               Long           não      Identificador da avaliação
  fipeId           String         não      Código FIPE  ex: "001015-9"
  veiculo          VeiculoObject  sim      null se o veículo ainda não estiver
                                           cacheado localmente
    ├─ marca       String         —        ex: "Fiat"
    ├─ modelo      String         —        ex: "Uno"
    ├─ ano         Integer        —        ex: 2020
    └─ combustivel String         —        ex: "Gasolina"
  precoDesejado    Double         não      Preço anunciado pelo vendedor
  precoFipe        Double         não      Preço de tabela FIPE na data da avaliação
  variacao         Double         não      ((precoDesejado − precoFipe) / precoFipe)
                                           × 100. Negativo = abaixo do FIPE.
  statusResultado  Enum           não      Ver seção Enums
  conservacao      Enum           não      Ver seção Enums
  kmsRodados       Double         não      Quilometragem informada
  notasPessoais    String         não      Observações do usuário
  avaliacaoIA      String         sim      Análise gerada por IA. null se o serviço
                                           estiver indisponível.
  criado_a         LocalDateTime  não      Data/hora de criação
  historicoAtivo   Enum           não      "SIM" ao criar; "NAO" após soft delete


┌─────────────────────────────────────────────────────────────────────────────┐
│  POST /sc                                                          200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Cria uma nova avaliação. brandId, modelId e yearId devem ser obtidos
  previamente via rotas /fipe.

  Request
  ───────
  Campo           Tipo        Obrig.  Descrição
  brandId         String      sim     Código da marca  (campo "code" de GET /fipe)
  modelId         String      sim     Código do modelo (campo "code" de GET /fipe/marcas/{brandId}/modelos)
  yearId          String      sim     Código do ano    (campo "code" de GET /fipe/marcas/.../anos)
                                      Formato: "AAAA-C"  ex: "2020-1"
  kmsRodados      Double      sim     Quilometragem atual do veículo
  precoDesejado   Double      sim     Preço anunciado pelo vendedor
  conservacao     Enum        sim     Ver seção Enums
  notasPessoais   String      sim     Observações livres do comprador

  Response  200   →  AvaliacaoResponse  (ver objeto acima)
                     historicoAtivo sempre "SIM" na criação.

  Erros
  ─────
  400  campo ausente, nulo ou valor inválido para conservacao
  401  token ausente, expirado ou inválido


┌─────────────────────────────────────────────────────────────────────────────┐
│  GET /sc                                                           200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Retorna todas as avaliações ativas do usuário autenticado.
  Avaliações com historicoAtivo = "NAO" não são incluídas.
  Retorna array vazio [] quando não há avaliações ativas.

  Response  200   →  Array de AvaliacaoResponse

  Erros
  ─────
  401  token ausente, expirado ou inválido


┌─────────────────────────────────────────────────────────────────────────────┐
│  PATCH /sc/{id}                                                    200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Realiza soft delete da avaliação: altera historicoAtivo de "SIM" para "NAO".
  O registro permanece no banco. A operação é irreversível pelo front-end.

  Path variable
  ─────────────
  id   Long   ID da avaliação a desativar

  Response  200   →  AvaliacaoResponse com historicoAtivo = "NAO"

  Erros
  ─────
  401  token ausente, expirado ou inválido
  403  avaliação pertence a outro usuário
  404  avaliação com o ID informado não existe


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ROTAS FIPE  (/fipe)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Todas as rotas /fipe exigem token. Os campos retornados usam nomes em inglês.
  Os valores "code" de cada rota alimentam a próxima como path variable,
  e os três códigos finais (brandId, modelId, yearId) são enviados no POST /sc.

  Fluxo em cascata:
    GET /fipe  →  GET /fipe/marcas/{brandId}/modelos
              →  GET /fipe/marcas/{brandId}/modelos/{modelId}/anos
              →  (opcional) GET /fipe/marcas/{brandId}/modelos/{modelId}/anos/{yearId}

  Objeto NameCode  (retornado pelas três primeiras rotas)
  ───────────────────────────────────────────────────────
  Campo  Tipo    Descrição
  name   String  Nome legível  ex: "Fiat", "Uno", "2020 Gasolina"
  code   String  Código a usar como path variable na etapa seguinte
                 Usar sempre "code", nunca "name", como identificador.


┌─────────────────────────────────────────────────────────────────────────────┐
│  GET /fipe                                                         200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Lista todas as marcas de veículos disponíveis na tabela FIPE.

  Response  200   →  Array de NameCode
  Erros     401


┌─────────────────────────────────────────────────────────────────────────────┐
│  GET /fipe/marcas/{brandId}/modelos                                200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Lista os modelos de uma marca.

  Path variable
  ─────────────
  brandId  String  Código obtido em GET /fipe

  Response  200   →  Array de NameCode
  Erros     401


┌─────────────────────────────────────────────────────────────────────────────┐
│  GET /fipe/marcas/{brandId}/modelos/{modelId}/anos                 200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Lista os anos/combustíveis disponíveis para um modelo.

  Path variables
  ──────────────
  brandId  String  Código da marca
  modelId  String  Código do modelo

  O code retornado segue o formato "AAAA-C":
    1 = Gasolina  |  2 = Álcool  |  3 = Diesel
  Exemplos:  "2022-1" (Gasolina 2022),  "2021-3" (Diesel 2021)

  Response  200   →  Array de NameCode
  Erros     401


┌─────────────────────────────────────────────────────────────────────────────┐
│  GET /fipe/marcas/{brandId}/modelos/{modelId}/anos/{yearId}        200 OK   │
└─────────────────────────────────────────────────────────────────────────────┘

  Retorna os dados completos e o preço FIPE de um veículo específico.
  Rota opcional — use para exibir o preço FIPE antes de submeter o POST /sc.

  Path variables
  ──────────────
  brandId  String  Código da marca
  modelId  String  Código do modelo
  yearId   String  Código do ano  ex: "2020-1"

  Response  200
  ─────────────────────────────────────────────────────────────────────────────
  Campo            Tipo     Descrição
  price            String   Preço FIPE formatado  ex: "R$ 48.500,00"
  brand            String   Nome da marca         ex: "Fiat"
  model            String   Nome do modelo        ex: "Uno"
  modelYear        Integer  Ano do modelo         ex: 2020
  fuel             String   Tipo de combustível   ex: "Gasolina"
  codeFipe         String   Código FIPE           ex: "001015-9"
  referenceMonth   String   Mês de referência     ex: "maio de 2026"

  Erros     401

  POST    /auth/login                                             não    200      400, 401

  GET     /sc                                                     sim    200      401
  PATCH   /sc/{id}                                                sim    200      401, 403, 404
  GET     /fipe                                                   sim    200      401
  GET     /fipe/marcas/{brandId}/modelos                          sim    200      401
  GET     /fipe/marcas/{brandId}/modelos/{modelId}/anos           sim    200      401
  GET     /fipe/marcas/{brandId}/modelos/{modelId}/anos/{yearId}  sim    200      401
